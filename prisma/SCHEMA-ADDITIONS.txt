SCHEMA ADDITIONS - CONTENT REMOVAL NOTIFICATIONS
================================================

Do NOT replace prisma/schema.prisma. In "enum NotificationType { ... }", add one
value at the end, so the enum ends with:

  CHAPTER_UNLOCKED
  CONTENT_REMOVED
}

The matching migration is in this package:
  prisma/migrations/20261117100000_notify_content_removed/migration.sql

Apply it with deploy, because the shadow database is still broken:

  npx prisma validate
  npx prisma generate
  npx prisma migrate deploy
  npx prisma migrate status    (should say the database is up to date)
