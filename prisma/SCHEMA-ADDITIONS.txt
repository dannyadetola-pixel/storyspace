SCHEMA ADDITIONS - GROUP PHOTOS
===============================

Do NOT replace prisma/schema.prisma. Find "model Conversation { ... }" and
add this line next to "name String?":

  avatarUrl String?    // group photo; null shows the default group icon

Then run:

  npx prisma validate
  npx prisma generate
  npm run prisma:migrate      (name it: add_group_avatars)
