SCHEMA ADDITIONS - RECENT SEARCHES
==================================

Do NOT replace prisma/schema.prisma. Paste these into it.

1. Inside "model User { ... }", next to the other relations, add:

  recentSearches RecentSearch[]

2. At the bottom of the file, add this model:

model RecentSearch {
  id        String   @id @default(cuid())
  userId    String
  query     String
  createdAt DateTime @default(now())

  user User @relation(fields: [userId], references: [id], onDelete: Cascade)

  @@unique([userId, query])
  @@index([userId, createdAt])
}

Then run:

  npx prisma validate
  npx prisma generate
  npm run prisma:migrate      (name it: add_recent_searches)
